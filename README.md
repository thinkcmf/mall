ThinkCMF 8.1.0 电商解决方案 开发版
===============
**`8.1.0`正在紧张开发中，请不要用于正式环境！


### 主要特性

* `MIT`开源协议,让你飞得更高,行得更远
* 基于`ThinkPHP 8.1`
* 多应用架构
* 应用中心
* 支持插件机制
* 支持多模板
* 支持模板可视化设计
* 支持`RESTful API`
* 支持`Swagger API`文档
* 支持数据库迁移
* 支持`Docker`运行

### 环境推荐

> PHP 8.2     
> MySQL 5.7+   
> 打开rewrite

### 最低环境要求

> PHP 8.2  
> MySQL 5.5   
> 打开rewrite

### 安装程序

1. public目录做为网站根目录,入口文件在 public/index.php
2. 配置好网站，请访问http://你的域名

enjoy your cmf~!

### Swagger

#### 开启Swagger

后台应用中心->插件管理安装 `Swagger`插件(要求PHP8.1及以上)
